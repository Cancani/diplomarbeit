Lernumgebungen mit dem Agenten bereitstellen

Sie beschreiben die Maschine in einer YAML-Datei und erstellen sie mit einem Befehl, auf KubeVirt genauso wie auf AWS. Auf dieser Seite stellen Sie die Befehle zusammen und kopieren sie direkt ins Terminal. Die Hintergründe stehen in der Lernunterlage zur Schulung.

    Merke: Die Plattform geben Sie nur beim Erstellen an, alle anderen Befehle finden sie im gespeicherten Zustand. Zu jedem Befehl gibt es eine Hilfe, zum Beispiel python -m agent reset --help.
    

    


    
  
    Den Status lesen
    
  
    status --name zeigt zwei Dinge: was der Agent gespeichert hat und was die Plattform gerade meldet. Ob die Lernenden arbeiten können, entscheidet die hervorgehobene Zeile. Adresse, Ports und Kennung im Beispiel sind Platzhalter.
    
  
    
  
    
    
    Zugang in die Maschine
    Den Zugang öffnen Sie vom Agentenhost aus, Host und Port stehen in der Zeile SSH: ssh -i <privater Schlüssel> -p <Port> ubuntu@<Host>. Auf AWS gilt Port 22, dort lassen Sie -p <Port> weg. Nach einem Reset können sich Adresse und Port ändern.
    
    
    Praxisfrage: Die Ausgabe zeigt «VM: Läuft», aber noch nicht «HTTP-Dienst: Bereit». Können die Lernenden schon mit der Maschine arbeiten?

      Mehrere Maschinen als Gruppe
      
    
      Mit --count entstehen mehrere gleiche Maschinen auf einmal. Aus --name klasse --count 3 werden klasse-1, klasse-2 und klasse-3. Auf KubeVirt startet --parallel mehrere Erstellungen gleichzeitig.
      
    
      Mit derselben Anzahl wirken auch status, reset und delete auf die ganze Gruppe. Reset und Abbau laufen dabei nacheinander. Eine einzelne Maschine sprechen Sie mit ihrem vollen Namen an.
      
    
      Bricht eine Gruppe ab, nennt die Meldung eine gemeinsame Kennung. Mit dieser Kennung setzt derselbe Befehl die ganze Gruppe fort.

        Grenzen des Proof of Concept
        
  
        Die Maschinen enthalten Ubuntu und den Testdienst, aber noch keine Modulsoftware. AWS läuft im AWS Academy Learner Lab, dessen Sitzungen zeitlich begrenzt sind. Bevor der Agent im Unterricht eingesetzt werden kann, müssen Zuständigkeiten, Berechtigungen und das Aufräumen nicht mehr benötigter Maschinen geregelt werden.
